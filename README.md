# PFE - Analyse vocale d'un formateur à partir d'une vidéo

## Objectif
Développer un système intelligent qui analyse une vidéo de cours en ligne afin d'évaluer la performance vocale d'un formateur.

## MVP
Pipeline complet :
vidéo -> audio -> prétraitement -> features -> scores -> PDF

## Stack
Python, Librosa, FFmpeg/MoviePy, NumPy/SciPy, Matplotlib, ReportLab, Scikit-learn"# p.pfe"
